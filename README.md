# Jimoto — 地元の体験・飲食店の予約アプリ（MVP）

日本語しか使えない小さな事業者が自分で店舗を登録し、訪日客がそれを一覧で見つけて、言葉の壁なしにチャットと予約まで進めるアプリ。
仕様は [docs/spec.md](docs/spec.md)（MVP縮小版）。前の版（元の仕様書をフルに作った版）は git の参照 `refs/backup/before-mvp-rebuild` に残してある。

## 2つの画面

| URL | 使う人 | 言語 |
| --- | --- | --- |
| `/` | ロゴ → 「旅行者」か「お店の方（事業者）」かを選ぶ。旅行者は一覧・地図・詳細をログインなしで見られ、チャット・予約はメールアドレス＋パスワードで登録 | 英語・簡体字・繁体字・韓国語 |
| `/biz` | 事業者。スマホファースト | 日本語 |

### 旅行者
- **ロゴの画面**：トップを開くたびに、まずロゴだけ。タップすると「旅行者」か「お店の方（事業者）」かを選ぶ（店の詳細ページに直接来た人には出さない）
- **最初の検索**：行先（日本列島のイラストから地方 → 都道府県 → 市区町村、または「現在地の近く」）・日付・人数。初回は言語と通貨を選ぶ（端末の設定から推定）
- **検索結果**：一覧と地図を切り替え。カードに写真、値段帯（＋自国通貨の目安）、今日から1週間の〇△✕（検索した人数で判定）、地元のお客さんの割合の帯グラフ、営業年数、最寄り駅と距離、タバコ・ペット・個室、特典の印、デモの店には「サンプル」。絞り込みはカテゴリ・予算・地元の割合・営業年数・駅からの距離・タバコ・ペット・個室・特典。地図は「このあたりで探す」で範囲を絞れる。キャラクターが端に小さく出て一言
- **詳細**：写真、特典、地元の割合、一番人気・店主のおすすめ、店主のこだわり、設備、地図、外部リンク、「この店舗を報告」
- **チャット**：自分の言語で書くと日本語で届き、返信は自分の言語で読める。原文も見られる
- **予約**：最初の検索の日付と人数が入った状態から。上限人数の内なら即時確定（同時の予約はDBのロックで順に処理）
- **右上の三本線のメニュー**：予約の確認、メッセージ、アカウント、言語と通貨、規約、問い合わせ

### 事業者
- **店舗**：日本語で入力 → 保存すると英語・簡体字・繁体字・韓国語に翻訳。市区町村（日本列島から選ぶ）、最寄り駅と距離、写真（8枚まで）、地図でピン、値段帯、地元のお客さんの割合、設備、一番人気・店主のおすすめ・こだわり、特典、時間枠（何時から何時まで・何名まで）、定休日、受付締切。必須がそろえば即公開
- **予約**：新着の印。画面を開いている間は、新しい予約で音が鳴る（最初に「音をオンにする」を押す）。理由を選んでキャンセル
- **受付停止**・**チャット**（予約したお客様には自分から話しかけられる。ブロック）

通知はメールではなく、画面の未読バッジと通知音。メールはパスワード再設定だけ送る。

## 外部サービス

| 機能 | 環境変数 | ないとき |
| --- | --- | --- |
| DB（PostgreSQL / Neon） | `DATABASE_URL`、`DATABASE_URL_UNPOOLED`（テーブル作成用） | 動かない |
| 写真の保存（Vercel Blob） | `BLOB_READ_WRITE_TOKEN` | 写真を登録できない（ほかは動く） |
| 自動翻訳（Gemini API） | `GEMINI_API_KEY`、`GEMINI_MODEL`（既定 `gemini-3.8-flash`） | 翻訳せず日本語の原文を出す |
| メール（Resend） | `RESEND_API_KEY`、`MAIL_FROM`、`APP_URL` | 送らない。開発中は再設定のリンクをサーバーのログに出す |
| 地図 | OpenStreetMap（キー不要。出典の表示が必要） | － |
| 為替 | ExchangeRate-API（キー不要） | 最後に取れたレートと取得日時を出す |

## セットアップ

```bash
npm install
npm run db:push    # DB の "mvp" スキーマに空のテーブルを作る（ほかのスキーマには触らない）
npm run dev        # http://localhost:5173
```

本番用の DB（mvp スキーマ）に仮のデータは入れない。空の DB から動く。

### デモ用の店（300店）

発表・確認用に、別のスキーマ `demo` に架空の店を全国47都道府県に300店入れられる（すべて「サンプル」の印つき）。

```bash
npm run demo:push   # demo スキーマにテーブルを作る
npm run demo:seed   # 中身を消して、架空の店を300店入れ直す
npm run dev:demo    # demo スキーマを使う開発サーバー（http://localhost:5174）
```

デモの店の事業者アカウントは `demo-shop-001@example.com`〜`demo-shop-300@example.com`、パスワードは `demo-password`（`DEMO_PASSWORD` で変えられる）。

### 都道府県・市区町村のデータ

`lib/data/` と `public/data/` のデータ（47都道府県、1,741市区町村、日本地図）は `scripts/build_japan.py` で作る（作り方は先頭のコメント）。

```bash
npm test           # 予約のルール（lib/domain.js）の単体テスト
```

## 運営の作業（管理画面の代わり）

```bash
npm run ops -- review              # 2日以内に保存された店舗と、未確認の報告（毎日確認する）
npm run ops -- suspend <placeId>   # 店舗を非公開に（unsuspend で戻す）
npm run ops -- checked <reportId>  # 報告を確認済みに
npm run ops -- kpi 30              # 成功指標（直近30日。日数を省くと全期間）
```

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/traveler/` | 旅行者の画面 |
| `src/biz/` | 事業者の画面 |
| `src/components/` | 共通部品（ログイン、チャット、地図、日本列島から行先を選ぶ、キャラクター、写真がないときのイラスト） |
| `src/i18n/` | 旅行者画面の文言（en / zh / zt / ko。キーは `en.js` と同じ） |
| `src/legal.jsx`、`src/legalTraveler.js` | 利用規約・プライバシーポリシー（旅行者は4言語、事業者は日本語） |
| `api/` | Vercel Functions（7個）：`auth` `places` `bookings` `messages` `biz` `photos` `rates` |
| `lib/domain.js` | 予約と掲載のルール（選択肢・日付・空き枠）。画面と API の両方で使う |
| `lib/japan.js`、`lib/cities.js` | 地方・都道府県・市区町村 |
| `lib/auth.js` | ログイン（scrypt・セッション Cookie・回数制限） |
| `lib/translate.js` | 自動翻訳（Gemini。掲載文は1回で4言語に） |
| `lib/photos.js` | 写真の保存先（Vercel Blob） |
| `prisma/schema.prisma` | DB の設計 |
| `scripts/ops.js` | 運営の作業 |
| `scripts/demo-seed.js` | デモ用の架空の店（demo スキーマにだけ入れる） |

## 公開する前に

- `src/legal.jsx` の `OPERATOR`（運営者名・問い合わせ先）は**仮の値**。GitHub に上げる前・本番公開の前に差し替える
- 本番の環境変数：`DATABASE_URL`・`GEMINI_API_KEY`・`RESEND_API_KEY`・`MAIL_FROM`・`APP_URL`（本番の URL）
- DB のバックアップ：Neon の復元（Point-in-time restore）の保持期間を確認する
- 利用規約・プライバシーポリシーは、本格的な運用の前に専門家に確認する
